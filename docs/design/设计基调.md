# 个人展示网站设计基调 v1

这份设计基调作为后续视觉与交互设计的基准，先确定视觉与体验，不进入具体实现。

## 定位与气质

一个以文字为主角的个人数字展览，突出前端风格化设计和交互能力。以瑞士平面的严谨秩序为基础，通过超大尺度、运动排版和局部三维形成强烈、实验性的表达。

## 核心母题

**文字打破秩序，再建立新的秩序。**

名字、个人定位和作品标题在滚动中经历裁切、错位、拆分与重组，最终形成下一段清晰的内容布局。

## 视觉语言

| 元素 | 职责 |
|---|---|
| 超大文字 | 首屏主角、身份表达、章节重心 |
| 网格 | 统一对齐关系，为文字变化提供参照 |
| 矩形 | 内容窗口、色块、蒙版与转场载体 |
| 分割线 | 划分信息、连接章节、提示边界 |
| 网点 | 局部印刷质感，用于图像与过渡画面 |
| 三维对象 | 与文字穿插、遮挡，提供局部空间感 |

标题允许跨栏、贴边和超出屏幕；正文与辅助信息保持稳定、清晰。字体以有力量的无衬线为主，辅助标签可使用等宽字体。

## 色彩体系

- 白 `#FFFFFF`：留白与阅读空间。
- 黑 `#111111`：主要文字与视觉重量。
- 亮蓝 `#2450FF`：主要强调色，承担大面积背景和空间场景。
- 亮黄 `#FFE600`：关键词、交互反馈与关键转场。

**蓝色占据面积，黄色控制注意力。** 常规场景以黑白搭配一种强调色，高潮场景允许蓝黄同时出现。

## 动效与浏览节奏

以文字平移、蒙版揭示、尺度变化和排版重组为主要动作；视差、闪动与三维集中用于少数关键场景。短标题可以逐字运动，正文保留充分的阅读停顿。

连续滚动连接各个展区，分段式滚动用于精选作品的场景演变。Loading 在确有资源等待时出现，Splash 与 Hero 合并为一次完整的文字亮相，Transition 延续矩形遮罩与文字重组的语言。

## 技术表达方向

GSAP 承担排版动作、滚动节奏与场景编排；Three.js 承担围绕文字展开的空间关系。具体技术方案在后续实现阶段确定。

## 设计判断标准

访客首先记住你的名字与表达，其次感受到交互设计能力，并能顺畅理解作品、找到联系方式。每个场景有一个明确的视觉重心，强烈变化之间留出安静的阅读空间。
