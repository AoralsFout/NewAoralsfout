# Showcase

AoralsFout 的个人展示页面，使用 Vue 3、TypeScript 和 Vite。内容围绕现有后端数据设计：GitHub 置顶项目、技术栈、开发活动与贡献日历，NeoBlog 文章，Steam 游戏库和 Bangumi 动画书架。GSAP 与 Three.js 提供滚动动效和首页装置，字体使用系统字体。

## 启动与构建

在仓库根目录执行：

```powershell
npm ci
npm run dev
```

展示页访问 http://localhost:5173，管理页访问 http://localhost:5174，后端监听 http://localhost:3002。已有后端在运行时，可以仅执行：

```powershell
npm run dev -w showcase
npm run build -w showcase
npm run preview -w showcase
```

开发端口固定，端口占用时直接报错。构建包含 Vue / TypeScript 类型检查，产物位于 showcase/dist，预览端口默认 4173。

## 公开数据

页面默认使用 API，先读取 /api/showcase/modules，再请求清单允许公开且可用的模块。请求只使用 GET，不发送身份 Cookie，不访问管理 API，也不触发上游采集。

| 展区 | 公开模块或入口                                            | 使用内容                                                 |
| ---- | --------------------------------------------------------- | -------------------------------------------------------- |
| 代码 | github.pinned、github.activity、github.contributions      | 仓库介绍、语言、Star、链接，活动日期与事件，实际每日贡献 |
| 技术栈 | github.languages | 各公开置顶仓库的语言、代码字节数与仓库内占比 |
| 文字 | neoblog.articles                                          | 标题、摘要、标签、日期、封面、原文链接                   |
| 游戏 | steam.profile、steam.status、steam.games                  | 昵称、头像、主页、可用状态、游戏图标、游玩时长、最近游玩 |
| 动画 | bangumi.collections                                       | 五类收藏、实际海报、名称、本人评分与条目链接             |
| 关于 | github.profile、/api/personal-status、/api/learning-goals | GitHub 简介、公开统计、有效近况与公开学习目标            |
| 联系 | contacts、/api/contacts | 后台配置的公开联系方式、文本、链接与复制操作 |

隐藏模块不展示，隐藏条目由后端过滤；空结果保持空，空的近况、学习目标和联系方式不添加示例。缓存不可用或接口失败会显示对应状态，失败可重新加载。API 模式不会降级为 mock，也不会插入概念项目、虚构文章或其他兴趣条目。固定姓名和首页文案属于前端配置；联系方式来自后台列表。

列表按公开接口分页，初次每页 12 条；“更多”追加下一页并去重。Bangumi 看过、在看、想看、搁置和抛弃分别查询，总数属于当前分类。切换会取消旧请求，较早响应不会覆盖新分类。每个来源显示后端提供的缓存状态与更新时间，不声称缓存是实时数据。时间戳统一使用 Asia/Shanghai；贡献日历保留接口的日历日期。

文章 API 仅提供摘要，因此详情显示摘要和“阅读原文”，不虚构正文或阅读时长。图片使用接口提供的地址，加载失败时保留排版与条目名称。原文和封面域名由后端的 NeoBlog 配置提供；本地地址需要对应博客服务运行。

## 前端配置

需要覆盖默认值时，复制 showcase/.env.example 到 showcase/.env，然后重启开发服务器；生产环境需要重新构建。

| 变量                    | 默认值                        | 说明                                              |
| ----------------------- | ----------------------------- | ------------------------------------------------- |
| VITE_SHOWCASE_DATA_MODE | api                           | mock 仅用于显式离线设计预览，页面持续标注演示模式 |
| VITE_SHOWCASE_API_BASE  | /api                          | 公开 API 基址，开发同源代理到 localhost:3002      |

联系方式在管理页 `/contacts` 维护，需同时开启条目可见性和 `contacts` 模块；原有 `VITE_CONTACT_EMAIL`、`VITE_PERSONAL_EMAIL`、`VITE_CONTACT_URL` 不再使用。`src/config/contact.ts` 只负责安全链接：优先使用 HTTP(S) 地址；无地址时，`email` 和 `phone` 分别生成邮件或拨号入口，其他自定义类型展示可复制的纯文本。VITE_ 变量会进入浏览器，只能填写公开配置。

## 交互与可访问性

项目支持真实语言筛选与详情弹窗，文章支持摘要与原文入口，游戏和动画直接链接对应平台。贡献日历提供日期提示与可通过键盘展开的最近 28 天文字明细。联系弹窗提供各类联系方式复制；复制失败时仍可手动选中文本，有链接的条目可跳转。

技术栈区域直接请求 github.languages，按语言筛选对应仓库，并用比例条和可读图例展示每个仓库的语言构成。项目数统计当前已读取的公开仓库，底部展示分页总量；不把代码占比当作个人熟练度，不从仓库名称推断额外框架。空内容与接口失败保留真实状态。

章节按滚动位置分段展开：标签侧向淡入，主标题逐字上移入场，说明与来源信息随后出现；项目、技术栈、文章、游戏和动画条目按可见行错峰入场，个人统计和联系入口也随所在片段展开。元素完全离开可视范围后复位，上下滚动再次进入时重播；仅越过入场阈值、仍在视口内时保持可见。筛选、分页和数据同步只注册新增节点，不打断正在呈现的内容。开发动态列表也支持内部滚动时反复入场。

贡献日历保留 API 的真实颜色与次数，进入视口后按日期逐格点亮，完全离开后可再次播放；按热图整体观察可视范围，不为每个日期建立监听，点亮过程约 1.8 秒。动效只使用位移、缩放与透明度，播放结束释放临时合成提示；异步数据更新合并刷新布局。

各展区使用局部网格、点阵、矩阵和斜纹，纹理位于内容下方，不接收交互；窄屏降低密度与对比。首屏矩阵、代码区条纹和日常区点阵仅作少量缓慢位移或透明度变化，离开视口或切到后台标签页时暂停；减少动态偏好下保留静态图案，不持续动画。静态纹理由 src/background.css 管理，动态点缀由 PatternAccent 组件提供。

手机使用折叠菜单。原生 dialog 支持 Escape、焦点约束和关闭后焦点恢复。键盘焦点进入尚未播放的条目时立即完成入场，标题读屏名称保持完整。减少动态偏好下关闭 GSAP 入场与滚动动画，运行中切换偏好也会还原静态可见状态；三维装置延迟加载，离开视口后暂停，无 WebGL 时保留 CSS 替代图。

## 部署

将 showcase/dist 部署为静态站点，由所在域名将 /api 转发至后端；Vite 代理仅在开发环境生效。展示页和管理页分别构建、分别部署。新环境须在管理页明确开启需要公开的模块及条目。
