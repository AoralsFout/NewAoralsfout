# Showcase

AoralsFout 的个人展示页面，使用 Vue 3、TypeScript 和 Vite。内容围绕现有后端数据设计：GitHub 置顶项目、技术栈、开发活动与贡献日历，NeoBlog 文章，Steam 游戏库和 Bangumi 动画书架。GSAP 与 Three.js 提供滚动动效和首页装置。字体通过 Fontsource 自托管：英文大字使用带宽度轴的 Archivo，等宽标签使用 JetBrains Mono，中文标题使用 900 字重的 Noto Sans SC（按 unicode-range 分片按需下载），中文正文仍使用系统字体。

## 启动与构建

在仓库根目录执行：

```powershell
npm ci
npm run dev
```

展示页访问 http://localhost:5173，管理页访问 http://localhost:5174，后端监听 http://localhost:3002。已有后端在运行时，可以仅执行：

```powershell
npm run dev -w showcase
npm run build -w showcase
npm run preview -w showcase
```

开发端口固定，端口占用时直接报错。构建包含 Vue / TypeScript 类型检查，产物位于 showcase/dist，预览端口默认 4173。

## 公开数据

页面默认使用 API，先读取 /api/showcase/modules，再请求清单允许公开且可用的模块。请求只使用 GET，不发送身份 Cookie，不访问管理 API，也不触发上游采集。

| 展区 | 公开模块或入口                                            | 使用内容                                                 |
| ---- | --------------------------------------------------------- | -------------------------------------------------------- |
| 代码 | github.pinned、github.activity、github.contributions      | 仓库介绍、语言、Star、链接，活动日期与事件，实际每日贡献 |
| 技术栈 | github.language-stats | 全部仓库的语言占比、代码字节数与使用仓库数量 |
| 文字 | neoblog.articles                                          | 标题、摘要、标签、日期、封面、原文链接                   |
| 游戏 | steam.profile、steam.status、steam.games                  | 昵称、头像、主页、可用状态、游戏图标、游玩时长、最近游玩 |
| 动画 | bangumi.collections                                       | 五类收藏、实际海报、名称、本人评分与条目链接             |
| 关于 | github.profile、/api/personal-status、/api/learning-goals | GitHub 简介、公开统计、有效近况与公开学习目标            |
| 联系 | contacts、/api/contacts | 后台配置的公开联系方式、文本、链接与复制操作 |

隐藏模块不展示，隐藏条目由后端过滤；空结果保持空，空的近况、学习目标和联系方式不添加示例。缓存不可用或接口失败会显示对应状态，失败可重新加载。API 模式不会降级为 mock，也不会插入概念项目、虚构文章或其他兴趣条目。固定姓名和首页文案属于前端配置；联系方式来自后台列表。

列表按公开接口分页，初次每页 12 条；“更多”追加下一页并去重。Bangumi 看过、在看、想看、搁置和抛弃分别查询，总数属于当前分类。切换会取消旧请求，较早响应不会覆盖新分类。每个来源显示后端提供的缓存状态与更新时间，不声称缓存是实时数据。时间戳统一使用 Asia/Shanghai；贡献日历保留接口的日历日期。

文章 API 仅提供摘要，因此详情显示摘要和“阅读原文”，不虚构正文或阅读时长。图片使用接口提供的地址，加载失败时保留排版与条目名称。原文和封面域名由后端的 NeoBlog 配置提供；本地地址需要对应博客服务运行。

## 前端配置

需要覆盖默认值时，复制 showcase/.env.example 到 showcase/.env，然后重启开发服务器；生产环境需要重新构建。

| 变量                    | 默认值                        | 说明                                              |
| ----------------------- | ----------------------------- | ------------------------------------------------- |
| VITE_SHOWCASE_DATA_MODE | api                           | mock 仅用于显式离线设计预览，页面持续标注演示模式 |
| VITE_SHOWCASE_API_BASE  | /api                          | 公开 API 基址，开发同源代理到 localhost:3002      |

联系方式在管理页 `/contacts` 维护，需同时开启条目可见性和 `contacts` 模块；原有 `VITE_CONTACT_EMAIL`、`VITE_PERSONAL_EMAIL`、`VITE_CONTACT_URL` 不再使用。`src/config/contact.ts` 只负责安全链接：优先使用 HTTP(S) 地址；无地址时，`email` 和 `phone` 分别生成邮件或拨号入口，其他自定义类型展示可复制的纯文本。VITE_ 变量会进入浏览器，只能填写公开配置。

## 交互与可访问性

项目支持真实语言筛选与详情弹窗，文章支持摘要与原文入口，游戏和动画直接链接对应平台。贡献日历提供日期提示与可通过键盘展开的最近 28 天文字明细。联系弹窗提供各类联系方式复制；复制失败时仍可手动选中文本，有链接的条目可跳转。

技术栈区域直接请求 `github.language-stats`，以排版树图（Squarified 算法，语言名本身即色块，面积按代码字节分配）和文本图例展示全部仓库的代码构成，并显示语言种类、统计仓库数、含代码仓库数及总代码量。该接口返回单个汇总对象，不分页，不展示逐仓库明细；统计包含公开、私有、Fork 和归档仓库，不把代码占比当作个人熟练度。有效零统计保留汇总指标，空内容与接口失败保留真实状态。该模块有独立的公开开关，默认隐藏，需在管理页开启“全部仓库语言统计（含私有）”后展示，与置顶仓库模块开关无关。

章节按滚动位置分段展开：标签侧向淡入并由乱码解码为原文，主标题先由每行一块矩形遮罩扫过、字符交替从上下错位归位，说明与来源信息随后出现；项目、技术栈、文章、游戏和动画条目按可见行错峰入场，个人统计和联系入口也随所在片段展开。元素完全离开可视范围后复位，上下滚动再次进入时重播；仅越过入场阈值、仍在视口内时保持可见。筛选、分页和数据同步只注册新增节点，不打断正在呈现的内容。开发动态列表也支持内部滚动时反复入场。

贡献日历保留 API 的真实颜色与次数，宽屏通栏铺满、格子随列宽缩放，窄屏回到固定格并允许横向滚动；进入视口后按日期逐格点亮，总量数字同步从零滚动到真实值（读屏始终读取真实总量），完全离开后可再次播放；按热图整体观察可视范围，不为每个日期建立监听，点亮过程约 1.8 秒。动效只使用位移、缩放与透明度，播放结束释放临时合成提示；异步数据更新合并刷新布局。

各展区使用局部网格、点阵和斜纹，纹理位于内容下方，不接收交互；窄屏降低密度与对比。全站另叠一层很淡的颗粒与 12 栏细线（窄屏 4 栏），打印时移除。代码区条纹和日常区点阵仅作少量缓慢位移或透明度变化，离开视口或切到后台标签页时暂停；减少动态偏好下保留静态图案，不持续动画。静态纹理由 src/background.css 管理，动态点缀由 PatternAccent 组件提供。

## 首屏与场景

首屏姓名分前后两层：后层完整显示，前层只保留少数字母，三维结形雕塑铺满舞台，在字母之间前后穿插。两行姓名按舞台宽高分别计算字号贴边，字体加载后重新测量。页头悬浮在内容之上，压在蓝色舞台时透明反白。

每个浏览器会话首次进入时播放开场：白幕中线生长（等待字体最多 1.2 秒），白幕沿中线上下分开，错位的字母吸附归位，雕塑与介绍随后出现。会话存储不可用时照常播放；直接带锚点进入其他展区、减少动态偏好或键盘焦点进入页面时跳过或立即结束。

桌面宽度（≥768px）且允许动态时，首屏固定约 1.5 屏的滚动距离：两行姓名向两侧撕开拉伸，雕塑回到中心、结心正对镜头，相机穿过结心，最后白色矩形从中心铺满并接入代码区；窄屏只保留姓名的轻微视差。

代码区最前面的三个置顶仓库组成精选场景：蓝、黑、黄三幅整屏色块，超大描边编号与按最长单词贴满宽度的标题。宽度 ≥900px 且允许动态时舞台固定，滚动推动矩形遮罩自下而上逐个揭开下一件作品；键盘焦点进入被遮住的作品时滚动到对应位置。其他情况下纵向排列。下方的“全部仓库”索引仍列出全部仓库并支持语言筛选。

文字区与日常区之间是两条交叉倾斜的蓝黄跑马条，速度和倾斜随滚动速度变化，离开视口或切到后台时停止。动画海报与文章封面在可悬停设备上默认为蓝白网点印刷效果，悬停或聚焦时还原原图；触屏直接显示原图。桌面鼠标下有跟随指针的黄色方块光标，悬停卡片时展开为 OPEN 等标签，进入弹窗时隐藏；首屏入口与联系圆球带磁吸效果；联系区描边字以指针为圆心局部填充黄色。

手机使用折叠菜单。原生 dialog 支持 Escape、焦点约束和关闭后焦点恢复。键盘焦点进入尚未播放的条目时立即完成入场，标题读屏名称保持完整。减少动态偏好下关闭开场、首屏与精选场景的固定、跑马条、自定义光标、磁吸及 GSAP 入场与滚动动画，运行中切换偏好也会还原静态可见状态；三维装置延迟加载，离开视口后暂停，无 WebGL 时保留 CSS 替代图。

## 部署

将 showcase/dist 部署为静态站点，由所在域名将 /api 转发至后端；Vite 代理仅在开发环境生效。展示页和管理页分别构建、分别部署。新环境须在管理页明确开启需要公开的模块及条目。
